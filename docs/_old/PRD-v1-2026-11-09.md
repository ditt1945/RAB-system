## 1. Latar Belakang

Kontraktor UMKM menyusun RAB lewat spreadsheet: format berantakan, rumus mudah salah, versi RAB tidak terlacak, dan dokumen untuk klien tidak konsisten. RABKita mengganti spreadsheet dengan aplikasi web: input volume × harga satuan, hitung subtotal/total otomatis, simpan revisi, ekspor PDF siap kirim ke klien.

## 2. Tujuan Produk

1. Menyusun RAB proyek konstruksi dalam hitungan menit, bukan berjam-jam.
2. Memastikan angka konsisten: satu sumber perhitungan (`src/lib/calculations/rab.ts`), dihitung server-side dengan `Decimal.js`.
3. Menjaga jejak audit: setiap perubahan RAB bisa direvisi dan dibandingkan.
4. Menghasilkan dokumen RAB PDF profesional dengan identitas perusahaan.

### Non-goals (di luar scope v1)

- Manajemen proyek lapangan (progress fisik, timesheet, Gantt).
- Pembayaran / invoice / accounting.
- Kolaborasi multi-user real-time pada satu dokumen.
- Mobile native app.

## 4. Ruang Lingkup Fitur (v1)

### 4.1 Autentikasi & Akun
- Register (validasi Zod + hashing `bcryptjs`), login NextAuth Credentials, session.
- Profil pengguna (`/profile`): nama, telepon, departemen, catatan.
- Role: `admin`, `estimator`, `manager`, `client` (enum `UserRole`, disimpan di `ProfileSetting`).

### 4.2 Manajemen Proyek
- CRUD proyek (`/projects`, `/projects/new`, `/projects/[id]`).
- Field: nama proyek, klien, deskripsi, tanggal mulai/selesai, status (`planning` → `progress` → `completed` / `cancelled`).
- Parameter RAB per proyek: diskon (`rabDiscount`), pajak (`rabTaxPercent`, default 11%), biaya jasa (`rabServiceFee`), target margin (`targetMarginPercent`, default 15%).

### 4.3 Item RAB
- CRUD item per proyek: nama, kelompok (`groupName`), kategori, volume, satuan, harga satuan.
- Subtotal item = `volume × unitPrice` (2 desimal).
- Setiap item bisa ditautkan ke master material (`materialId`, opsional).

### 4.4 Perhitungan RAB (otoritatif)

```
itemsSubtotal   = Σ (volume × unitPrice)
afterDiscount   = max(0, itemsSubtotal − discount)
taxAmount       = afterDiscount × taxPercent / 100
marginAmount    = (afterDiscount + serviceFee) × marginPercent / 100
grandTotal      = afterDiscount + taxAmount + serviceFee + marginAmount
```

Semua dihitung server-side. Klien tidak pernah mengirim angka total yang dipercaya begitu saja.

### 4.5 Master Material
- CRUD material per akun (`/materials`): nama, kategori, satuan, harga satuan, supplier, deskripsi.
- Harga material menjadi template harga satuan saat item RAB dibuat.

### 4.6 Revisi RAB
- Simpan snapshot JSON isi RAB + subtotal + grand total + label/catatan (`RabRevision`).
- Riwayat revisi per proyek untuk audit dan perbandingan versi.

### 4.7 Change Order
- Ajukan perubahan lingkup kerja: judul, deskripsi, nominal, tanggal diminta.
- Status: `draft` → `submitted` → `approved` / `rejected`.

### 4.8 Rekomendasi AI (Gemini)
- User kirim prompt kebutuhan proyek → `AiRequest` (`pending` → `processing` → `completed` / `failed`).
- Hasil berupa saran item/material JSON, user pilih untuk dimasukkan ke RAB.

### 4.9 Estimasi Rumah Cepat
- Form cepat: tipe rumah, luas bangunan, luas tanah, jumlah kamar, kualitas (`hemat`/`standar`/`premium`), lokasi → total estimasi + rincian (`HouseEstimation`).
- Hasil tersimpan dan tercatat di `EstimationAnalytic` (rata-rata estimasi per periode).

### 4.10 Export PDF
- Endpoint `/api/projects/[id]/pdf` memakai PDFKit, streaming ke client.
- Header dokumen memakai `CompanySettings` (nama, alamat, logo perusahaan).

### 4.11 Pengaturan Perusahaan & Permintaan Penawaran
- `/company-settings`: identitas perusahaan untuk kop dokumen.
- `QuotationRequest`: permintaan penawaran dari pengunjung landing page (`pending` → `reviewed` → `contacted`).

## 5. Kebutuhan Non-Fungsional

| Kategori | Syarat |
|---|---|
| Akurasi | Perhitungan desimal wajib `Decimal.js`, bukan float JS; pembulatan 2 desimal |
| Keamanan | Password `bcryptjs`; session NextAuth; data proyek/material scoped per user (`createdBy` / `ownerId`) |
| Performa | Halaman dashboard < 2 detik pada dev lokal; query material terindeks (`ownerId+name`, `ownerId+category`) |
| Data | MariaDB/MySQL via Prisma 7; soft dependency: relasi `onDelete: Cascade` pada proyek → item |
| Kompatibilitas | Chrome/Edge modern, viewport mobile 390px |
| Pengujian | Vitest untuk unit test mesin perhitungan RAB |
| Bahasa UI | Bahasa Indonesia |

Detail lengkap: `prisma/schema.prisma`.

## 8. Kriteria Penerimaan (Acceptance Criteria)

1. Register → login → dashboard menampilkan proyek milik user sendiri saja.
2. CRUD proyek + item RAB tersimpan; subtotal item = volume × harga satuan, cocok hingga 2 desimal.
3. Grand total sesuai rumus di §4.4 saat diskon/pajak/jasa/margin diubah.
4. Simpan revisi menghasilkan baris `RabRevision` dengan snapshot benar.
5. Change order berpindah status sesuai alur dan tercatat di proyek.
6. Request AI berubah `pending` → `completed`, saran bisa diterima jadi item RAB.
7. Export PDF menghasilkan file terbaca dengan kop `CompanySettings`.
8. Material hanya terlihat oleh pemiliknya.

## 10. Risiko

| Risiko | Mitigasi |
|---|---|
| Perbedaan angka client vs server | Total selalu dihitung server-side |
| Key Gemini bocor / kuot habis | State `AiRequest` gagal ditampilkan jelas, fitur tetap jalan tanpa AI |
| Kunci asing material dihapus | `onDelete: SetNull` pada `RabItem.material` — item RAB tetap ada |
| Data legacy Laravel berbeda skema | `docs/migrasi-legacy.md` + skrip di `scripts/` |
